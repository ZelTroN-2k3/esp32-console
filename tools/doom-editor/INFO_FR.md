# ⌨️ E-OS DOOM Level Editor - Raccourcis Clavier (HELP)

Bienvenue dans le guide des raccourcis clavier de l'éditeur de niveau. 
L'utilisation de ces raccourcis vous permettra de construire vos cartes beaucoup plus rapidement sans avoir à faire d'incessants allers-retours avec votre souris dans les menus.

## 🔄 Historique & Actions
- **`Ctrl + Z`** : Annuler la dernière action (Undo). Remonte dans l'historique de vos coups de pinceau.
- **`Ctrl + Y`** (ou **`Ctrl + Shift + Z`**) : Refaire l'action annulée (Redo).

## 🛠️ Outils Rapides
Ces touches vous permettent de basculer instantanément d'un outil à l'autre en un seul clic :
- **`E`** : **Gomme (Eraser).** Permet d'effacer les murs (Tiles) ou les objets (Sprites) sur lesquels vous cliquez.
- **`P`** : **Joueur (Player Start).** Permet de déplacer le point d'apparition du joueur. Cliquez à nouveau sur le joueur avec cet outil pour le faire pivoter (Nord, Est, Sud, Ouest).
- **`T`** : **Dernier Mur (Tile).** Vous redonne en main le tout dernier type de mur que vous aviez sélectionné dans la palette. Très pratique pour reprendre le tracé des murs après avoir posé un monstre.
- **`S`** : **Dernier Objet (Sprite).** Vous redonne en main le tout dernier objet ou monstre que vous aviez sélectionné.

## 💾 Gestion des Fichiers
- **`Ctrl + S`** : **Sauvegarder (Save).** Exporte et écrase le fichier `.h` actuel si vous travaillez sur un fichier déjà ouvert.
- **`Ctrl + O`** : **Ouvrir (Load Level).** Ouvre la fenêtre pour charger un niveau existant.

## 🖱️ Navigation à la Souris
- **Clic Gauche (Maintenu)** : Peindre / Placer l'élément sélectionné en continu.
- **Clic Droit (Maintenu) + Glisser** : Se déplacer (Pan) librement sur la carte sans avoir à utiliser les barres de défilement.
- **Molette de la Souris** : Zoomer / Dézoomer de x1 jusqu'à x10.
- **Clic sur la Mini-Map** : Vous téléporte instantanément à l'endroit cliqué.
