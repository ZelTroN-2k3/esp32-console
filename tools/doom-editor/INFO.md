# ⌨️ E-OS DOOM Level Editor - Keyboard Shortcuts (INFO)

Welcome to the level editor keyboard shortcuts guide. 
Using these shortcuts will allow you to build your maps much faster without having to constantly go back and forth with your mouse in the menus.

## 🔄 History & Actions
- **`Ctrl + Z`**: Undo the last action. Goes back in the history of your brush strokes.
- **`Ctrl + Y`** (or **`Ctrl + Shift + Z`**): Redo the canceled action.

## 🛠️ Quick Tools
These keys allow you to instantly switch from one tool to another with a single click:
- **`E`**: **Eraser.** Allows you to erase the walls (Tiles) or objects (Sprites) you click on.
- **`P`**: **Player Start.** Allows you to move the player's spawn point. Click on the player again with this tool to rotate them (North, East, South, West).
- **`T`**: **Last Tile.** Gives you back the very last type of wall you had selected in the palette. Very practical for resuming drawing walls after placing a monster.
- **`S`**: **Last Sprite.** Gives you back the very last object or monster you had selected.

## 💾 File Management
- **`Ctrl + S`**: **Save.** Exports and overwrites the current `.h` file if you are working on an already opened file.
- **`Ctrl + O`**: **Load Level.** Opens the file dialog to load an existing level.

## 🖱️ Mouse Navigation
- **Left Click (Hold)**: Paint / Place the selected element continuously.
- **Right Click (Hold) + Drag**: Move (Pan) freely around the map without having to use the scrollbars.
- **Mouse Wheel**: Zoom in / out from x1 up to x10.
- **Click on the Mini-Map**: Instantly teleports you to the clicked location.
